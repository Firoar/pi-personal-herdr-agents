# Attribution

## Ponytail

`skills/ponytail/SKILL.md` is vendored from
[`DietrichGebert/ponytail`](https://github.com/DietrichGebert/ponytail)
(`skills/ponytail/SKILL.md`), MIT licensed. The upstream project also ships
always-on extensions and commands for several agents; this pack vendors only the
skill text so the rules can be declared on the `team-senior` role alone.

## Research method

`skills/team-research/SKILL.md` adapts the method from
[`mattpocock/skills@research`](https://skills.sh/mattpocock/skills/research),
MIT licensed. The upstream skill opens by delegating research to a background
agent; that step is removed here because `team-researcher` is already that
agent. The primary-source and citation rules are retained.
